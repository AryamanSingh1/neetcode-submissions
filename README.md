# 🧠 NeetCode Submissions

My solutions to the [NeetCode 150](https://neetcode.io/practice), written in **C++**.
Everything here is pushed automatically from NeetCode.io whenever I submit.

## Why this exists

I'm building real problem-solving skill and preparing for technical interviews.
The aim is to learn the patterns behind the problems (hash sets, two pointers,
sliding window and so on), not to collect green ticks.

## How I practise

1. Try the problem on my own for 20-25 minutes.
2. If stuck, study the solution, then rewrite it from scratch without looking.
3. Redo it a week later. If I can't, it doesn't count as learned.
